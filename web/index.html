Lift the text off the page

Turn flattened PDFs and exported exam papers into clean, editable Markdown, Word, PDF and JSON, with figures intact. Then see proof that nothing went missing.

Try it in your browser Download the app

No sign-up. No upload. The web version runs entirely in your browser tab.

Built to be trusted

Reusing a flattened PDF usually means retyping it. Paperlift rebuilds the structure and checks its own work.

Clean, editable output

Headings, lists, tables and figures come out as Markdown, Word, PDF or JSON. No stray line breaks or repeated headers.

Exam-paper mode

Exported exam papers are split into questions and options, and the answers are collected into a key.

Fidelity audit

Every source word and image is accounted for, with a score, page-level findings and an annotated copy of the source.

Private by design

Nothing is uploaded. The extraction runs on your own computer, in the app or inside your browser.

File manager

Group files into folders, drag to organise, rename, and download everything at once in the formats you choose.

Open source

AGPL-3.0, inspectable end to end. The browser build runs the same Python code as the desktop app.

Get the download

Download Paperlift

Unzip, double-click, done. Everything it needs is kept inside its own folder, so deleting the folder removes it completely.

Windows

Windows 10 or 11 · needs internet once
Download for Windows
  1. Unzip the download (right-click, Extract All) somewhere you keep apps, such as Documents.
  2. Open the paperlift folder and double-click Start Paperlift.bat.
  3. If Windows SmartScreen appears, choose More info, then Run anyway. The scripts are plain text you can read.
  4. The first start downloads its own Python and libraries (about 240 MB). Then your browser opens Paperlift at 127.0.0.1:8765.
Close the black window to stop Paperlift. Your files are in the inbox and output folders next to the launcher.

macOS

macOS 11 or newer · Apple silicon and Intel
Download for macOS
  1. Unzip the download by double-clicking it, then move the paperlift folder somewhere permanent.
  2. The first time, right-click Start Paperlift.command and choose Open, then confirm. After that, double-click works.
  3. The first start downloads its own Python and libraries (about 240 MB). Then your browser opens Paperlift.
Prefer Terminal? cd paperlift && ./paperlift.sh. Press Ctrl+C in the window to stop.

Linux

Any 64-bit distribution with bash and curl or wget
Download for Linux
  1. Unzip it: unzip paperlift-linux.zip
  2. Start it: cd paperlift && ./start-linux.sh (or ./paperlift.sh)
  3. The first start downloads its own Python and libraries (about 240 MB). Your browser opens Paperlift at 127.0.0.1:8765.
No sudo needed and nothing is installed system-wide. If the script is not executable, run chmod +x *.sh first.
